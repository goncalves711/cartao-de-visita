1. Suba o conteúdo desta pasta para um repositório no GitHub.
2. Importe o repositório na Vercel como projeto estático (sem build).
3. Abra a URL pública e teste os links, contato e QR Code.
4. No NFC Tools, grave URL/URI com o endereço público HTTPS.
5. Confira antes de colar o adesivo.

Para atualizar links, edite index.html.
O QR Code será exibido após publicar e abrir a página via HTTPS.
